# GenCAD 专题知识库

MIT 团队提出的 **GenCAD** 与 **GenCAD-3D** 系列工作：从非参数化几何（图像、点云、网格）生成可编辑的 **参数化 CAD 程序**（命令序列），而非仅输出 mesh/voxel 等难以工程编辑的表示。

## 阅读顺序

1. [comparison.md](./comparison.md) — 两篇工作的关系、差异与演进
2. [digest-gencad.md](./digest-gencad.md) — **GenCAD**：图像条件 CAD 生成（arXiv:2409.16294）
3. [digest-gencad-3d.md](./digest-gencad-3d.md) — **GenCAD-3D**：多模态几何条件 + SynthBal（arXiv:2509.15246）
