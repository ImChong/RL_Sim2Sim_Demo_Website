# 知识库

本目录存放经整理的**原始资料**与**消化摘要**，供人类开发者与 AI Agent 在需要 CAD 生成、逆向工程或多模态几何建模背景时查阅。

## 目录结构

| 路径 | 说明 |
|------|------|
| [sources.json](./sources.json) | 全部来源 URL、类型与收录日期（机器可读索引） |
| [gencad/](./gencad/) | GenCAD（图像条件）与 GenCAD-3D（三维几何条件）专题 |

## 使用方式

1. **快速了解**：先读 [gencad/README.md](./gencad/README.md) 与两篇消化文档。
2. **核对细节**：在 `gencad/sources/` 下对照原始摘录与官方 README。
3. **扩展收录**：新增主题时复制 `gencad/` 子目录结构，并更新 `sources.json` 与本文件索引。

## 收录原则

- **原始资料**：项目页、论文摘要、仓库 README 等摘录，保留出处链接，不替代官方文档。
- **消化文档**：用中文归纳架构、数据、训练/推理流程及与相关工作的关系，便于 Agent 一次性建立上下文。
